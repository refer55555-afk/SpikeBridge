# Spike Bridge 安装助手交接说明

本次新增的是一个由人操作的本机安装助手，不会自动执行安装，也不会启动、停止或重启 Spike Bridge。

## 使用方法

1. 双击 `Spike Bridge 安装助手.exe`。
2. 阅读说明后，点击“安装面板开机任务（需确认）”。
3. 在 Windows 管理员确认窗口中自行决定是否允许。
4. 只有已审核脚本 `scripts/system.ps1 -Action startupEnable` 返回退出代码 0 时，助手才会报告脚本成功。
5. 成功后仍需返回中文面板，重新检查 `SpikeBridge-Operator` 任务状态。

取消管理员确认或脚本返回非零退出代码时，助手会明确报告“安装未完成”。

“浏览器问题说明”只解释 Codex A 的 `.codex` / sandbox 目录访问问题。该助手不会修改 ACL、绕过或关闭沙箱，也不会宣称浏览器问题已经修复；应使用 Codex 官方浏览器/沙箱安装或修复流程后重新验证。
